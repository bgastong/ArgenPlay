# ArgenPlay

Plataforma web de videojuegos desarrollada con React que permite explorar, buscar y filtrar juegos.

## Tecnologias
- React
- CSS
- API REST
- React Router
- localStorage
- Vercel

## Funcionalidades
- Busqueda de juegos
- Filtros por genero
- Vista de detalle
- Favoritos
